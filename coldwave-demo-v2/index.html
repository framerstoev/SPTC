Method and limitations

Experimental method

  • Q(t) = speed / baseline speed profile; Q = 1 means baseline-level speed performance.
  • Candidate B uses the dominant sustained performance drop.
  • Detection uses a 6-hour centered rolling median, 0.90 x Q0 threshold, and k = 3 consecutive observations.
  • Tier 3 metrics are observed operational labels; Tier 1/2 variables are predictor/context layers.
  • Score classes are experimental v0 quantile classes.

Limitations

  • This is not the stable dashboard score.
  • Delay burden is supplemental user-impact information.
  • Profile volume is not observed event-day volume.
  • Phase detection is sensitive to smoothing, threshold, data coverage, and noise.
